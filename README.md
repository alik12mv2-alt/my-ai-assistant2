# دستیار هوش مصنوعی شخصی

این مخزن شامل نسخهٔ اولیهٔ دستیار متنی فارسی برای اجرا در Termux است.

## نیازمندی‌ها
- Python در Termux
- API key از یک سرویس سازگار با API گفت‌وگو

## راه‌اندازی
1. مخزن را در Termux کلون کنید.
2. فایل نمونهٔ تنظیمات را به `.env` کپی کنید.
3. کلید API را در `.env` تنظیم کنید (کلید را در GitHub یا گفتگوها منتشر نکنید).
4. اجرا: `python main.py`

## فرمان‌های برنامه
- `reset`: پاک‌سازی تاریخچهٔ گفت‌وگو
- `exit` یا `quit`: خروج
