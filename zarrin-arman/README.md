# زرین آرمان | ZARRIN ARMAN

نمونه اولیه وب‌سایت فروشگاهی طلا با رابط فارسی و راست‌چین، تم مشکی/طلایی و طراحی واکنش‌گرا.

## ویژگی‌ها
- صفحه اصلی برند زرین آرمان
- کارت‌های قیمت **نمونه و غیرواقعی**
- کاتالوگ نمونه
- محاسبه‌گر ارزش خام بر اساس وزن و عیار
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- پنل مدیریت کاتالوگ آزمایشی (`admin-demo.html`): افزودن/حذف محصول و ذخیره محلی در مرورگر
- لینک پنل مدیریت از صفحه اصلی

## اجرا
فایل `index.html` را با مرورگر باز کنید.

## وضعیت
این پروژه فعلاً یک نمونه رابط کاربری (demo) است. قیمت‌ها ساختگی‌اند و هیچ سفارش، پرداخت یا معامله واقعی انجام نمی‌شود.
