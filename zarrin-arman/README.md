# زرین آرمان | ZARRIN ARMAN

نمونه اولیه وب‌سایت کاتالوگ طلا با رابط فارسی، راست‌چین، طراحی واکنش‌گرا و تم مشکی/طلایی.

## امکانات
- صفحه اصلی برند و کاتالوگ نمایشی
- جستجو و دسته‌بندی محصولات
- کارت محصول با اطلاعات وزن و عیار
- فهرست انتخاب محصولات (صرفاً نمایشی)
- محاسبه‌گر ارزش تقریبی بر پایه وزن و عیار
- صفحه مدیریت کاتالوگ و افزودن/ویرایش محصولات (اتصال Supabase نیازمند تنظیم)
- نسخه آزمایشی مدیریت محلی مرورگر: `admin-demo.html`

## راه‌اندازی
برای مشاهده، فایل `index.html` را در مرورگر باز کنید یا پروژه را از GitHub Pages منتشر کنید.
برای پنل مدیریت متصل، ابتدا دستورهای فایل `supabase/schema.sql` را در پروژه Supabase اجرا و سپس تنظیمات عمومی را طبق [راهنما](./README-SETUP.md) انجام دهید. کلیدهای محرمانه یا `service_role` را در سایت یا مخزن قرار ندهید.

## وضعیت و محدودیت
این پروژه فعلاً نمونه/دمو است؛ قیمت‌ها نمایشی هستند. هیچ سفارش، پرداخت یا معامله واقعی فعال نیست. اتصال Supabase و انتشار نهایی باید جداگانه بررسی و تأیید شوند.
