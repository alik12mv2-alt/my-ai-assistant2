# راه‌اندازی زرین آرمان

## ۱) ایجاد دیتابیس Supabase
1. در Supabase پروژه خود را باز کنید.
2. به SQL Editor بروید.
3. فایل `supabase/schema.sql` را از این پوشه باز کنید و تمام SQL را اجرا کنید.

## ۲) ساخت حساب مدیر
1. از Authentication > Users یک حساب ایجاد کنید.
2. UUID کاربر را کپی کنید.
3. در SQL Editor اجرا کنید (UUID خودتان را جایگزین کنید):

```sql
insert into public.admin_users (user_id)
values ('YOUR-USER-UUID-HERE')
on conflict (user_id) do nothing;
```

## ۳) اتصال کاتالوگ عمومی
فایل `supabase-public-config.js` را باز کنید و Project URL و کلید عمومی anon/publishable را وارد کنید. این فایل در مرورگر بازدیدکنندگان نیز بارگیری می‌شود؛ پس فقط کلید عمومی را استفاده کنید. هرگز `service_role` یا secret key را در آن قرار ندهید.

## ۴) پنل مدیریت
پس از انتشار، صفحه `admin.html` را باز کنید. تنظیمات اتصال در پنل به صورت محلی در مرورگر مدیر ذخیره می‌شوند. ورود فقط برای حسابی ممکن است که UUID آن در جدول `admin_users` ثبت شده باشد.

## نکته
نسخه فعلی فروشگاه کاتالوگ و فهرست انتخاب نمایشی است؛ پرداخت و ثبت سفارش واقعی فعال نیست.
