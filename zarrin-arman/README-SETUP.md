# زرین آرمان — راهنمای انتشار و مدیریت\n\n## سایت زنده\n- فروشگاه: https://alik12mv2-alt.github.io/zarrin-arman2/\n- پنل کاتالوگ: https://alik12mv2-alt.github.io/zarrin-arman2/admin.html\n\n## مدیریت محصولات (بدون Supabase)\n1. پنل مدیریت را باز کنید.\n2. محصول اضافه کنید یا محصول موجود را ویرایش کنید.\n3. «دانلود JSON برای انتشار» را انتخاب کنید.\n4. در GitHub فایل `zarrin-arman/products.json` را باز کنید و محتویات JSON دانلودشده را جایگزین کنید.\n5. Commit کنید. GitHub Actions کاتالوگ را اعتبارسنجی و سایت را منتشر می‌کند.\n\n## درخواست سفارش\nفروشگاه فعلاً پرداخت آنلاین ندارد. مشتری می‌تواند اقلام را به سبد درخواست اضافه کند و فرم نام و شماره تماس را تکمیل کند؛ متن درخواست در دستگاه مشتری کپی می‌شود تا به راه ارتباطی رسمی فروشگاه ارسال شود. شماره تماس/واتساپ رسمی هنوز در سایت تنظیم نشده است.\n\n## قیمت و تصاویر\nقیمت‌های اولیه نمایشی حذف شده‌اند (صفر = قیمت برای استعلام). قیمت نهایی و موجودی باید قبل از معامله توسط فروشگاه تأیید شوند. تصاویر نمونه از URLهای خارجی استفاده می‌کنند؛ تصاویر محصول واقعی را با لینک HTTPS جایگزین کنید.\n\n## انتشار\nهر Commit در شاخه `main` باعث اجرای بررسی کاتالوگ و workflow انتشار GitHub Pages می‌شود. انتشار واقعی را از Actions با وضعیت موفق بررسی کنید.\n
